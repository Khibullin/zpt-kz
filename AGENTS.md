- **Уточнение согласовано владельцем 17.10.2026 (единая форма).** Обычные заявки `home_short` относятся к новым запчастям и направляются только подтверждённым продавцам с `Seller.sells_new_parts=True`. Признак `Seller.is_dismantler=True` независимо разрешает авторазборы. Оба признака — только для подтверждённо смешанных организаций; `sells_new_parts=None` означает «не проверено» и не даёт доступа к заявкам на новые запчасти. Исторические заявки не пересылать.
- Для обеих новых форм `home_short` покупатель может выбрать `search_scope='city'` (строго его город), `search_scope='custom'` (точно указанные `selected_cities`) либо `search_scope='kazakhstan'` (вся страна, по умолчанию). В вариантах city/custom нельзя автоматически расширять территорию. Старую логику формы `classic` не менять без отдельного задания.
- **Согласовано владельцем 17.10.2026:** заявки из раздела «Авторазборы» (`/find-part/?condition=used`, `Request.is_dismantler_request=True`) направляются **только** продавцам с `Seller.is_dismantler=True`. Проверять ограничение при подборе, постановке в очередь и отправке. Для обычных заявок и исторических очередей ничего не менять; не делать повторных отправок.

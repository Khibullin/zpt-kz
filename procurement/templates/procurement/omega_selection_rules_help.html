Правила отбора товаров из прайса

Действующие правила подготовки запросов Омеги для ручной проверки на Kaspi через Apify.

1. Источник данных

Выбор выполняется из загруженного прайс-листа Omega / Solid Prof Group. При загрузке читаются исходные «Подгруппа», бренд, артикул, цена, остаток и минимальная партия. Загрузка для анализа не применяет прайс к рабочим товарам автоматически. Отдельное обновление каталога требует подтверждения.

2. Выбор категорий

Показываются все категории из файла, включая пружины. Менеджер самостоятельно отмечает нужные категории. Повторное использование категории разрешено; рядом с ней показываются номера предыдущих запросов.

3. Закупочная цена

Менеджер вводит цену от 0 ₸. Граница включена: при значении 2 000 ₸ товар с закупочной ценой ровно 2 000 ₸ проходит. Каждый запрос сохраняет свой порог независимо от остальных.

4. Остаток

При включённом условии «Только товары в наличии» принимается только подтверждённый положительный остаток, включая обозначение Омеги «20>». Неизвестный или нулевой остаток не считается наличием.

5. Возраст автомобиля

Возраст задаёт менеджер для каждого запроса. Если в исходной подтверждённой применимости есть год, он сравнивается с установленным пределом. Если год отсутствует, товар не считается проверенным по возрасту и отдельно учитывается как требующий проверки. Нельзя определять возраст только по названию детали.

6. Результат отбора

До сохранения показывается число выбранных категорий, подходящих товаров, поисковых строк и JSON-партий. Поиск формируется из бренда и артикула; при наличии ведущих нулей добавляется корректный вариант без них. Одинаковые поисковые строки не дублируются.

7. История и выгрузка

Каждый сохранённый запрос получает номер, сохраняет прайс, категории, цену и возраст. Исторический запрос №1 от 20.11.2026 отображается справочно; его 9 ранее подготовленных JSON не выдаются за новые файлы. Новые запросы можно выгружать в Apify партиями по 500 поисков.

8. Безопасность

Создание запроса и выгрузка JSON не запускают Apify, не изменяют рабочие цены или остатки, не выбирают товар к закупке и не публикуют его в «Выгодные к закупке». Для применения результатов нужна отдельная проверка.

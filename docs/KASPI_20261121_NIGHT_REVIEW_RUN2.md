# Проверка Apify 21.11.2026: второй проход по ПОЛНОМУ JSON

Дата фактической проверки: 21.11.2026. Ветка `review/kaspi-20261121-overnight` — **только staging**, без развёртывания на zpt.kz и без изменений production-БД.

## Новое доказательство

Прочитан исходный сохранённый файл `dataset_kaspi-api_2026-11-21_14-00-09-125.json` полностью (436 карточек, 218 поисковых запросов, **все для Алматы**). Важное уточнение: поле `searchQuery` не определяет артикул найденной карточки. По полному бренду + **артикулу самой карточки** в её названии надо искать по всем 436 результатам, включая результаты чужого поискового запроса. Товар должен быть 1 шт., с реальными продавцами и ценами, надлежащей категорией, ID URL, положительным остатком поставщика и закупочной ценой ≥ 2 000 ₸. Пружины **разрешены**; по данной выборке не появилось предварительно прибыльных пружин.

Контрольные числа повторного аудита:
- 218 уникальных поисковых запросов;
- 185 проверяемых сочетаний бренд+артикул с подходящей карточкой из всех результатов;
- 105 сочетаний имеют позицию поставщика с положительным остатком и закупочной ценой ≥ 2 000 ₸;
- 87 из 105 ниже чистой доходности 50%;
- **18 предварительно проходят 50%**, но у всех `match_verified=false` и исполнение/характеристики не доказаны;
- 80 из 185 не найдены в текущем каталоге поставщика по порогу и точному артикулу;
- 23 совпадения обнаружены в результате запроса **другого артикула** — их нельзя отбрасывать без проверки карточки;
- валидированы реальные предложения продавцов, упаковка 250 ₸ учтена один раз, расчётная ставка комиссии — 12,5% из настроек admin.

## Изменение состава относительно первого ночного прохода

**Новое предварительное совпадение:** Omega **STINSS S2S1372**, Offer ID **4514**, закупка **8 145 ₸**, сохранённый положительный остаток **6**, Kaspi ID **105187710**, минимальная цена продавца **14 822 ₸** от RIMS (Алматы), расчётная прибыль **4 574,25 ₸**, ROI **56,1602%**, запас по дополнительным расходам до 50% — **501,75 ₸**. Карточка найдена в ответе на поисковый запрос `STINSS S2S1575`, поэтому прежний проход её упустил. Omega указывает **задний левый**, заголовок Kaspi подтверждает только «задний» и «1 шт.»; левую сторону, OEM и комплектность по вкладке характеристик Kaspi **не подтверждали**. Непригоден для публикации без проверки.

**Superzing 365757 по-прежнему исключён:** в исходном JSON дешевле карточка Kaspi **122329934** — **5 320 ₸** от «Алтын Авто», хотя она возвращена по запросу `Superzing 365753`. Другая карточка 179042686 — 10 763 ₸. С правильным минимумом 5 320 ₸ расчётный ROI **−15,9992%**.

### Несогласованность с production-аудитом (без изменения истории)

Проверка БД Render `zpt-kz-db`: миграция `0144_apify_20261121_second_export_review` создала для Superzing 365757 исходный аудиторский снимок **10 763 ₸, ROI 74,8212%**. Этот снимок устарел относительно исходной минимальной цены 5 320 ₸. В `PermanentBuyingItem` данного товара **нет**, поэтому непосредственно в накопительном реестре он сейчас не числится. Однако сохраняемый audit нельзя считать подтверждением его выгодности и нельзя использовать для будущего допуска к публикации. Старую запись не удаляли и не переписывали; нужна новая явная неразрушающая поправка и контроль запрета публикации при статусе `needs_review`.

Для нового S2S1372 в production уже есть `PermanentBuyingItem`, но аудита именно этого JSON и сравнительного материала нет. Новое соответствие включено только в staging.

## Осталось перед публикацией

1. Непосредственно открыть «Характеристики» выбранных оригинальных карточек Kaspi и подтвердить OEM, применимость, сторону L/R, количество в комплекте; данные Apify не использовать как источник подробных характеристик.
2. Подтвердить фактический тариф Kaspi по категории и прочие расходы; Superzing 57486 имеет запас всего 21 ₸, S2S1372 — 501,75 ₸.
3. Проверить минимумы других городов Казахстана; текущий файл охватывает только Алматы.
4. Исправить в будущем production-потоке проблему устаревшего аудита 365757 **с сохранением истории**, протестировать интеграцию правила межзапросной минимизации и убрать старое исключение пружин в `procurement/apify_price_recheck.py` (код там пока не согласован с новой политикой).
5. Только после всех проверок — перенос подтверждённых карточек «Подробнее» на сайт и разрешение к публикации. Ни одна из 18 пока такого статуса не имеет.

**Ограничения доступа:** исходные оригинальные страницы Omega и Kaspi по S2S1372 через используемый веб-доступ сейчас не открылись; поэтому техническое исполнение по первоисточникам не подтверждено. Пользовательские исходные цены, остатки, закупочные списки и заказы **не изменены**.

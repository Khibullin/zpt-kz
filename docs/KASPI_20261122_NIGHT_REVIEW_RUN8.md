## Важное новое: Kaspi Доставка может убрать часть условно выгодных позиций

- [Официальный тариф Kaspi Магазина 2026](https://guide.kaspi.kz/cdn/content/pay/product/documents/Magazin/Tarify_Magazina_na_Kaspi_kz_2026.pdf): автозапчасти в рассматриваемой категории — 10,9% без НДС, **12,5% с НДС**. Параметр модели 12,5% согласуется с тарифом; необходимо подтвердить применимость к каждому SKU/конкретной сделке.
- [Официальный Kaspi Гид: стоимость доставки, обновлено 16.06.2026](https://guide.kaspi.kz/partner/ru/shop/delivery/shipping/q2288): заказ от 10 000 ₸ весом до 5 кг — 1 099 ₸ по городу и 1 299 ₸ по Казахстану **без НДС**. При ставке НДС 16% сценарные полные суммы составляют **1 274,84 ₸ / 1 506,84 ₸** соответственно.
- Считаем только **для одного товара в отдельном заказе, вес до 5 кг, с Kaspi Доставкой**, а не для самовывоза/своей доставки; все 18 выбранных цен >10 000 ₸. Вес, канал доставки и объединение позиций в один заказ по SKU **не подтверждены**. НДС на доставку считается отдельно от комиссии.
- Формула для целей оценки: `ROI% = (цена Kaspi × 0,875 − закупка − 250 ₸ упаковки один раз − доставка с НДС) / закупка × 100`. Не включены налоги с продаж, возвраты и иные издержки; цены Kaspi — снимок только Алматы. Не называть это доказанной чистой прибылью.

**Сценарии:** без доставки 18/18 доходность ≥50%; с доставкой по городу 13/18; с доставкой по Казахстану 10/18. Это лишь чувствительность к тарифу, **к публикации допущено 0**.

## Новая защита идентичности, только staging

В `procurement/strict_apify_prepublication.py` выявлен пропущенный случай: если metadata `brand` совпадает с брендом поставщика, но в заголовке и URL Kaspi другой бренд с тем же артикулом, прежний валидатор мог принять его за целевой товар. Добавлена fail-closed сверка бренда по названию и URL карточки, три регрессионных теста в `procurement/test_strict_apify_prepublication.py`.

До этого прохода установлен успешный GitHub Actions-run на 27 чистых тестах: https://github.com/Khibullin/zpt-kz/actions/runs/44949455069. В новых коммитах обнаруживались синтаксические ошибки патча, устранены в `054b2c93b7650545763562cda9a82d26e4fed512`; **CI подтверждён**: [GitHub Actions #44954336464](https://github.com/Khibullin/zpt-kz/actions/runs/44954336464) — 30/30 изолированных Python-тестов пройдены, syntax check успешен именно на `054b2c93b7650545763562cda9a82d26e4fed512`. Полный Django/integration CI по-прежнему не проведён; не сливать в main без этого.

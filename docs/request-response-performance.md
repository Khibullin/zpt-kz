# Скорость заявки и списка продавцов

Отправка подтверждения больше не ждёт SMTP: после фиксации заявки существующее письмо владельцу передаётся двум фоновым потокам процесса. Содержимое, получатель и согласия не меняются. Потоки закрывают свои соединения БД и завершают задания при штатном останове процесса. Это не отдельная устойчивая очередь: при аварийном завершении процесса отправка не гарантируется, как и при прежней ошибке SMTP. Сама заявка уже сохранена. Для изолированных тестов `REQUEST_OWNER_EMAIL_ASYNC=False`; в рабочем режиме по умолчанию True.

Для списка используется облегчённое чтение полей сортировки и общая прежняя проверка `relevant()`. Названия марок проверяются через индекс слов, а не перебор всех марок для каждой организации. На 60 секунд сохраняется только порядок идентификаторов публичного каталога. Ключ зависит от заявки и её фильтров; токен не хранится в ключе открытым текстом. Кэш процесса не содержит цены, контакты, права доступа или персональные страницы. На показе десять карточек загружаются и проверяются заново. Прямые согласия и актуальные предложения продолжают рассчитываться без кэша. После изменения карточки порядок может обновляться до минуты; выключенная или переставшая соответствовать карточка не отображается уже при следующей проверке.

Показы регистрируются одним ограниченным INSERT с существующим уникальным ограничением. Повторное открытие не создаёт повторного показа и не подтверждает контакт. Карточка магазина и контактный POST проверяют одну конкретную организацию вместо повторного обхода всего каталога.

Локальный сравнительный прогон на синтетических 5000 продавцах и 1000 марках: прежний полный обход 1.55 с, первая страница после оптимизации 0.32 с, следующие страницы 0.014 с. Это изолированный SQLite-прогон, а не обещание времени production. Порядок идентификаторов проверен на совпадение. Регрессионные тесты проверяют ограничение работы десятью карточками, отзыв доступа, изменение марки/географии, отсутствие ложного контакта и независимость HTTP-ответа от задержки письма.

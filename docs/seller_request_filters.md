# Фильтр получения заявок продавцов и авторазборов

Согласовано владельцем 19.10.2026. СТО и детейлинг не входят в этот этап.

- Единая форма `/request-parts/filters/` в кабинете и `/sr/<token>/filters/` по действующей персональной ссылке заявки.
- Типы транспорта, марки, модели отдельно для каждой марки, категории запчастей. Явный выбор «Все» подтверждается сохранением.
- `Seller.request_filters = NULL` сохраняет старый подбор, без массового изменения специализаций.
- Подтверждённые фильтры проверяются при подборе, постановке в очередь, обработке волн и прямой отправке. Fallback их не расширяет. Если поле заявки неизвестно, ограниченный фильтр по этому полю не считается совпавшим.
- Старые поля профиля синхронизируются; карточки и кабинет показывают подтверждённую специализацию, включая модели по каждой марке и оба типа транспорта.
- Направления новых/б/у запчастей, город, волны, стоп-флаги и согласия WhatsApp не изменяются. Исторические заявки повторно не отправляются.
- Токен не даёт доступ к контактам/паролю/флагам организации. Действует существующий срок ссылки, есть CSRF и запрет кэширования. Тестовые организации не редактируются этой формой.

## Согласованный текст для утверждённого шаблона Meta

Откройте заявку, чтобы:
1. Посмотреть подробности и связаться с покупателем.
2. Настроить фильтр получения заявок.

Кнопка шаблона: «Открыть заявку». Статический текст изменяется в WhatsApp Manager и требует проверки Meta. Не подменять текст параметрами комментария покупателя и не менять рабочее имя шаблона до его утверждения.

## Порядок запуска

1. Подготовлен учёт источника именно у Request: GET `/find-part/` сохраняет UTM-метки в отдельной сессии на 7 дней; отправка формы копирует их в `campaign_attribution`. Повторная отправка с тем же ключом не меняет источник исходной заявки. Метки доступны сотрудникам в админке только для чтения. PR #197 объединён; версия 37f6e0daa18477a32d46494f5a321c99b8b89d5b опубликована на backend и worker 25.10.2026. Миграция 0130 и поле в PostgreSQL проверены. Серверная проверка захвата меток прошла без создания заявки; форма открывается после обновления. 49 локальных тестов прошли, дополнительных миграций Django не требует.
2. После разрешения на переписку получить конкретные предложения администраторов и проверить просмотры, географию и пригодность аудитории.
3. Согласовать конкретные площадки и цены. Предложенный суммарный предел 10000 тенге пока не считается утверждённым бюджетом.
4. Для каждой оплаченной площадки использовать отдельную метку кампании; проверить её сохранение перед публикацией.
5. Запустить 1–2 размещения. Считать расходы, переходы, реальные заявки, отклики, подтверждённый контакт и подтверждённую покупку отдельно. Не обещать гарантированный отклик или выгодность цены.
6. После первой новой реальной заявки начать согласованное подключение магазинов и авторазборов, показывая обезличенный реальный спрос. До этого приглашения не отправлять.

## Ограничения

- Уведомления продавцам — после привязки и согласия. Общий доступ к обезличенным заявкам не равен массовой отправке уведомлений.
- Неполная карточка не препятствует подключению; контакты покупателя защищены существующим механизмом идентификации и допуска.
- Сохранять географию и подтверждённые фильтры персональных уведомлений.
- WhatsApp — ручной канал, Meta API выключен. Автопубликацию в публичном Telegram не включать.
- Не пересылать исторические заявки и не публиковать повторно №515. Тестовые заявки не использовать как реальный спрос.
- Платные размещения не заказаны. Запросы условий отправлены только двум указанным администраторам; приглашения продавцам не отправлены.

# ZPT.KZ → AGParts.kz: защищённый API каталога v1

**Статус: рабочая ветка, API выключен по умолчанию. НЕ готов к боевому включению.** Изменения только в `feature/agparts-readonly-catalog-api`, без merge, деплоя, миграций, изменений товаров/цен/остатков или запуска фоновых задач.

## Принцип

API отдаёт **только проверенную продукцию собственного бренда** AG Parts — не любые товары продавца AG Parts. Факт `seller_profile.slug='ag-parts'` недостаточен: нужен отдельный явно утверждённый манифест с артикулом, категорией и тремя названиями.

Только четыре типа: `cabin`, `air`, `oil`, `spark`. ZPT `Product.brand` — марка автомобиля, это НЕ бренд товара.

## Маршруты (GET; server-to-server)

- `/internal/agparts/v1/products/` — список, максимум 50 на страницу, защищённый подписанный cursor.
- `/internal/agparts/v1/products/<product_id>/` — одна разрешённая карточка в общем формате каталога `agparts.catalog.v1`.
- `/internal/agparts/v1/vehicles/` — только исходные подтверждённые записи применяемости, `selection_ready:false` (встроенный алгоритм подбора ещё не согласован).

Маршруты не создают и не изменяют товары, склады, заказы, платежи, прайсы, WMS или рассылки. Существующие страницы ZPT.KZ не меняются.

### Настройка — пока НЕ включать в Render

Переменные окружения:

- `AGPARTS_CATALOG_API_ENABLED=False` — заводское состояние.
- `AGPARTS_CATALOG_API_TOKEN=` — отдельный случайный токен, не меньше 32 символов. Хранить только в секретах сервера.
- `AGPARTS_CATALOG_MANIFEST_JSON=` — утверждённый манифест, без каких-либо токенов или коммерческих секретов.
- `AGPARTS_KASPI_MERCHANT_ID=` — ID нашего магазина Kaspi, без него покупательские ссылки не выдаются; не является ключом API.

Только как **выдуманный образец**, не реальный товар:

```json
{
  "version": 1,
  "products": {
    "EXAMPLE-ARTICLE-001": {
      "official_brand_verified": true,
      "category": "cabin",
      "title": {
        "ru": "Тестовый салонный фильтр",
        "kk": "Сынақ сүзгісі",
        "zh": "测试滤清器"
      },
      "supplier_confirmed_at": null,
      "lead_time_days": null,
      "kaspi_pack_qty": null,
      "kaspi_master_sku": null
    }
  }
}
```

В ответе нет себестоимости, контактов продавцов, персональных данных покупателей, закрытого опта или токенов. Все поля заданы явным списком. Пользовательский браузер не получает API-токен и не обращается напрямую к `internal/agparts/`; обращения выполняет только сервер AGParts.kz через HTTPS.

Тестовая версия без манифеста, токена или разрешения возвращает 404/503 и никогда не отдаёт каталог.

## Цена, PP2 и поставка

- `retail_price_kzt` берётся только из `catalog.Product.price`, **не** из Kaspi или репрайсера.
- Доступный склад — исключительно `ProductWarehouseStock` склада `PP2`. PP1 не суммировать, `Product.stock_qty` игнорировать.
- Отсутствующий PP2 или просроченная дата обновления → 503, без выдачи частичного каталога и без обещания наличия.
- `stock_as_of` — **фактическая дата обновления исходной записи PP2**, не вымышленное текущее время.
- Статус `supplier_confirmed` только при нулевом PP2 и отдельном подтверждении поставщика. `lead_time_days` указывать только при таком подтверждении.
- Пока условные временные пороги в коде: **15 минут для PP2; 14 дней для подтверждения поставщика**. Это предварительные защитные ограничения, которые следует утвердить отдельно перед боевым включением.
- Для товаров без подтверждённого склада с нулём допускается `inquiry` только после свежей сверки PP2. Сам нулевой PP2 не означает доступность под заказ.
- На 21.10.2026 при read-only проверке в рабочей БД: 57 активных AG Parts; из них **52 устаревшие записи PP2 (сентябрь), 5 — без записи PP2**, 0 обновлённых за 15 минут. Поэтому текущее реальное содержимое **не должно** выдаваться как свежий склад. Сначала потребуется безопасно подтвердить актуальность данных WMS, без фиктивного обновления `updated_at`.

## Совместимость с автомобилями

Только `ProductFitment.status='confirmed'` после аудита `fitment_reviewed_on`, с `source_url`, `verified_on`, точными границами года и месяца, двигателем, кузовом, рынком, поколением, силовой установкой, мощностью и примечаниями. Записи с `engine_policy='unknown'` не трактовать как универсальные и не включать в автоматический подбор.

**Запрещено** превращать отсутствующий год в «любой год», игнорировать `month_from/month_to` или автоматически продлевать диапазон будущими годами. `vehicles.selection_ready=false` напоминает, что интерфейс подбора пока требует отдельной логики проверки.

## Kaspi и опт — новое согласованное правило 21.10.2026

**Владелец изменил ценовую политику:** основная розничная цена AG Parts на обоих сайтах должна соответствовать **цене нашего предложения Kaspi за ту же комплектацию**. Сентябрьские `last_known_our_price` и исторические `Product.price` сами по себе не дают право показывать «цену Kaspi».

Ссылка «Купить на Kaspi»:
- только из сохранённой карточки `ProductKaspiListing.public_url`, без конструирования URL по артикулу;
- запись активна, URL валидная HTTPS `/shop/p/`, присутствуют `m` именно нашего магазина и `ms=true`;
- `master_sku` соответствует **явно одобренному** `kaspi_master_sku` из манифеста, отдельно утверждён `kaspi_pack_qty` (1..100 шт.);
- `last_synced_at` с наблюдением нашей цены не старше **24 ч**, `last_known_our_price == Product.price` для той же упаковки; при расхождении ссылка скрывается до отдельной сверки;
- **флаги экспорта** `Product.publish_to_kaspi` и `listing.publish_to_kaspi` не являются критерием наличия публичной ссылки (текущая витрина ZPT уже использует независимо сохранённый URL). Изменение флагов выгрузки запрещено.
- при нескольких подходящих/спорных листингах ссылка скрывается, не делается выбор «первого попавшегося».

**Свеча F4J163707010:** владелец подтвердил, что 12 450 ₸ по снимку Kaspi 20.10.2026 — **за комплект четырёх штук**. В ZPT `Product.price=2450` относится к другой цене/упаковке и **не заменяется** 12 450 ₸ без отдельного решения о единице продажи. **Новое прямое решение владельца:** поштучную продажу свечей AG Parts исключить. Для `F4J163707010` допустимо **только предложение комплекта 4 шт.**, одиночную позицию не предлагать и не оставлять как отдельную альтернативу. Входной манифест запрещает `spark` с количеством 1 шт., а `F4J163707010` с количеством, отличным от 4 (null означает отсутствие подтверждённой покупки). Старая запись `Product.price=2450` остаётся нетронутой до отдельной безопасной миграции; ей нельзя выдавать цену комплекта или ссылку его покупки. Манифест пока не утверждён и не заполняется автоматически.

Для других артикулов количество в предложении нужно проверить в Kaspi. Сайт не должен выдавать ссылку покупки при неизвестной комплектности или несовпадающей цене. Проверка всего рынка, цены конкурентов и автоматическое обновление складских остатков этим API не выполняются.

Оптовые уровни `ProductPriceTier` пока намеренно не передаются; они требуют отдельного соглашения о правах дилера.

## Авторизация и безопасность

- Проверка отдельного Bearer-токена через constant-time сравнение; у выключенного API нет публичных данных.
- Rate-limit в коде — защитный **помесячно-минутный слот: не более 60 запросов/минуту на токен с использованием Django cache**. При будущем multi-worker-хостинге LocMem недостаточен, обязателен внешний общий лимит на серверном периметре или shared-cache. Кэш недоступен — отказ.
- Ответы `Cache-Control: private, no-store` и `X-Robots-Tag: noindex, nofollow`.
- Ошибки не содержат причину отказа по конкретному товару, SQL или значение токена.
- Пагинация подписывается Django signing; при изменении прайса, применяемости или склада snapshot_hash меняется и старый cursor отклоняется, без смешивания старых и новых данных.
- Требуется ручной аудит источников и прав использования фотографий/брендовых наименований до релиза.

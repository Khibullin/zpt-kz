# Подготовка JSON для Apify — служебные правила, 21.11.2026

## Назначение
Второй этап «Подготовки товаров к закупке» формирует входной JSON для ручного запуска в Apify. Он не выполняет запросы Kaspi и не изменяет закупочные цены, остатки или ранее сохранённые выборки.

## Источник
Использовать сохранённый запрос отбора Omega из первого блока. Выгружать бренд и полный артикул, сохраняя связь поискового запроса с исходным товаром. Закупочная цена не менее 2 000 ₸. Повторные запросы нормализуются и удаляются с сохранением исходной привязки.

## Параметры
- Шесть выбираемых городов: Алматы, Астана, Шымкент, Караганда, Актобе, Атырау. Интерфейс отмечает все шесть по умолчанию; выбор одного или нескольких допускается. Названия и поддержка должны быть сверены с конкретным Apify Actor до промышленного использования.
- На один запрос 1–5 карточек Kaspi, значение по умолчанию 2.
- Сортировка relevance, предложения продавцов включены, maxOffersPerProduct=0, отзывы отключены.
- Не более 500 поисковых запросов на один JSON.
- Лимит расходов до $10 за запуск устанавливается вручную в Apify, не обеспечивается экспортом JSON.

## Достоверность и обработка
Точное совпадение бренда и артикула проверяется при обработке результата Apify; попадание карточки по поисковому запросу не означает подтверждения. Выбор минимальной цены — только по предложениям продавцов проверенных карточек. Подробные характеристики Kaspi получать из оригинальной страницы карточки, а не подменять полями JSON. Правила 50% доходности применяются в третьем блоке.

## Обратная совместимость
Если параметры не переданы, экспорт формирует JSON со всеми шестью городами и 2 карточками на запрос. Несуществующие города и количество карточек вне диапазона 1–5 отклоняются. JSON-сопоставления привязок сохраняет прежний формат.

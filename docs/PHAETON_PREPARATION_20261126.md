# Подготовка закупок: три поставщика, 26.11.2026

Расширена существующая страница подготовки без новых страниц и дополнительных кнопок. Выбор в существующем поле переключает текущий прайс, историю загрузок, категории и историю запросов. Omega сохраняет прежнюю нумерацию и исторический первый запрос; новые поставщики начинают с №1. Снимки запроса содержат ID поставщика и хеш исходного прайса. Проверка перед сохранением запрещает случайное использование прайса другого поставщика.

Добавлены только отсутствующие справочники Phaeton DC / ZakazAuto; старые варианты названий продолжают работать без переименования или слияния данных. Миграция не удаляет данные и не переписывает исторические миграции.

Исходный прайс Фаэтона: 28 693 товарные строки; 28 674 уникальных бренд+артикул; 19 конфликтных сочетаний исключаются из автоматического отбора. Положительный остаток и цена от 2 000 ₸ после дедупликации и исключения конфликтов: 22 531. Используется «Цена», а не «Цена без скидки». Двухстрочный заголовок поддерживается штатным импортёром. Штрихкод и ТНВЭД сохраняются в исходных строках снимка, количество в упаковке — штатным полем. Без исходной категории применяется предварительная классификация по названию, без утверждений о применимости; 6 709 уникальных позиций остаются в «Без категории».

Платные проверки не запускаются при импорте. История категорий показывает ранее выбранные запросы. Для новых поставщиков уже подтверждённые аудиты не старше 7 дней исключаются при полном совпадении бренда, артикула, названия, закупочной цены, комплектности и связанной карточки. Список исключений заморожен в запросе, чтобы повторное скачивание JSON не менялось со временем. Повторные строки внутри запроса дедуплицируются.

Общий аудит Kaspi создаёт отдельные строки для предложений каждого поставщика: один бренд+артикул может получить общую наблюдаемую минимальную цену Kaspi, но собственную закупочную стоимость, прибыль и доходность. Ни закупочные цены, ни прежние аудиты и закупочные списки не объединяются. Подтверждение исполнения остаётся ручным. В карточке товара видны все предложения точного артикула, минимальная цена в наличии выделена.

Проверки: 15 тестов выбора поставщика, истории, прайса, отдельной доходности, защиты от чужого прайса и аудита Kaspi; 24 теста обновления прайсов — пройдены. В дополнительных старых тестах экспорта/интерфейса есть прежние несоответствия ожиданий (города Apify, число карточек, старая кнопка и формат печати); воспроизведены на исходном cb3c930b, не являются регрессиями этой доработки. `manage.py check` и проверка миграций приложения procurement пройдены. Общая проверка миграций выявляет прежнее изменение ID в repricer; оно не входит в эту работу.

Откат кода: исходный коммит cb3c930b8c8554830ca1a79f992a91d9e34cfbf5 сохранён резервной веткой. Новые справочники можно оставить: старая версия их скрывает. Сам прайс — отдельная запись PriceUpdate выбранного поставщика, Omega не меняется. Удаление записей для отката не требуется.

Полная загрузка выявила ограничение памяти PostgreSQL 256 MiB: исходный большой JSON не был сохранён (транзакция откатилась). Большие прайсы новых поставщиков теперь сохраняются сжатыми независимыми блоками по 500 строк; запрос чтения категорий и диапазон применения читают исходные данные через общий декодер. Legacy массивы Omega читаются прежним способом, без преобразования старых данных. Разбор и сжатие выполняются до захвата блокировки поставщика; в короткой транзакции повторно проверяются идемпотентность и дата. Повторная загрузка идентичного файла не создаёт дубликатов. Дополнительно проверены границы 499–701, сохранение исходных метаданных и частичное применение 200 строк из сжатого снимка. 40 профильных тестов пройдены.

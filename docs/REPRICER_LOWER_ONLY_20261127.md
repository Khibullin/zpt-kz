# Контроль цен Kaspi: исправления 27.11.2026

Согласованная задача: проверять сохранённые результаты, выбирать подтверждённые
предложения дешевле цены из ACTIVE и формировать Excel с ценой минимум × 0,97,
округляя вниз. Не запускать платный Apify и не отправлять цены в Kaspi автоматически.

Исправления:

- Внутренняя связь с каталогом ZPT не является условием экспорта цены по SKU
  ACTIVE. Требуются подтверждённое совпадение Kaspi, положительные цена и остаток,
  уникальный SKU, совпадение текущей цены в загружаемом шаблоне.
- Конкурент с ценой не ниже нашей не создаёт изменение. Проверка самого
  Excel-обработчика также запрещает повышение.
- Диапазоны годов 2011-2017 не являются артикулами. Числовой merchant_sku не
  используется как самостоятельный артикул детали. Различаются типы деталей.
- Указанный бренд другого производителя не становится идентичным лишь потому,
  что название содержит марку автомобиля. Например, 555 для Chery — не Chery.
- Название ACTIVE.xlsx допустимо: проверяется структура прайса, а не имя.
- Более дешёвые результаты с тем же артикулом/типом, но другим брендом
  сохраняются отдельно для сверки. Они видны и при наличии подтверждённой цены,
  доступны через фильтр «Проверить бренд» и не меняют подтверждённый минимум.

Проверены реальные сценарии: ошибочный Accent для упора EEP Camry исключается;
подтверждённые WXQP без внутренней связи участвуют в выгрузке; предложения 4S/AS
для Haval не включаются автоматически как идентичные изделия.

Развёртывание не требует новых миграций. Явный BigAutoField в модели черновика
выравнивает описание с существующей миграцией 0005 без изменения схемы.
Два устаревших UI-теста исправлены под существующие заголовки и расширенный
X-Robots-Tag; их исходные падения воспроизведены на базовом коммите 028d52f0.

Перед перепроверкой сохранить диагностику. Для полного известного набора
2312 записей использовать повторную загрузку без дополнения, чтобы старые
ошибочные совпадения не оставались в сохранённом минимуме. Это заменяет только
результаты сравнения; цены ACTIVE, склады и черновики сохраняются.

Откат кода: revert этого коммита; сохранённый исходный JSON позволяет заново
рассчитать сравнение. Сохранённые цены сравнения сами при откате не меняются.
Наличие записей по трём городам не доказывает полноту поиска всех карточек.

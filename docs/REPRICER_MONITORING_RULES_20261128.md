# Контроль цен Kaspi — правила от 28.11.2026

Область: мониторинг и подготовка Excel репрайсинга. Правила закупочного отбора сохраняются отдельно.

1. Источник — последний успешно загруженный полный ACTIVE.xlsx.
2. Проверенную нашу карточку проверять напрямую; альтернативы искать в категории Kaspi «Автотовары → Автозапчасти» (Replacement parts).
3. Для стабилизаторов использовать категорию Kaspi «Стабилизатор, крепление» (Anti Roll Bars).
4. Поисковая фраза — название детали и полный артикул. Поиск только по артикулу и поиск без категории запрещены; searchQueries пуст.
5. Полный артикул сравнивать с учётом пробелов и дефисов, сохраняя буквенные окончания. Разные производители, явные противоречия стороны, оси и комплектности исключать.
6. AG Parts — магазин. Для альтернатив с неизвестным производителем автоматическое подтверждение запрещено. Проверенная собственная карточка остаётся отдельным основанием идентификации при совпадении полного артикула и исполнения.
7. До 20 карточек на запрос; по умолчанию 20. Все доступные предложения продавцов; без отзывов. Наш merchant ID и настроенные собственные продавцы исключаются.
8. Минимум — среди найденных совпавших карточек и доступных продавцов выбранных городов. Это не гарантия абсолютного минимума всего Kaspi.
9. Дата проверки — из источника/запуска, не дата загрузки. При отсутствии даты в JSON оператор указывает фактическую дату запуска. Более старая дата источника не заменяется новой датой загрузки.
10. Срок актуальности — существующая настройка competitor_fresh_minutes (по умолчанию 180 минут). Устаревшие цены отмечать и блокировать в выгрузке новых цен.
11. Для выгрузки нужна свежая проверка каждого выбранного города. Новый город требует новой проверки. Дополнительный INPUT включает неподтверждённые, устаревшие и неполностью проверенные позиции.
12. Новая цена — целая часть минимума конкурента × 0,97. Только снижение при положительном остатке и текущей цене.
13. Нужен допустимый минимум. Использовать явный MIN оператора/включённого правила; защищать известную закупочную стоимость. При заданных комиссии и расходах учитывать себестоимость с ними; неизвестные расходы не выдумывать.
14. Неизвестный MIN блокирует Excel до ввода. Ручные изменения MIN сохранять с пользователем и прежним значением в журнале Activity для строки текущего ACTIVE.
15. Excel изменяет только выбранные цены в исходном шаблоне Kaspi. SKU, остатки, остальные строки и листы сохраняются. Изменение расчёта после предпросмотра требует повторной проверки.
16. Запуски Apify и загрузка Excel в Kaspi — вручную. Публикация кода не запускает сбор и не меняет реальные цены или остатки.

Реализация: repricer/identity.py, market_policy.py, apify_json.py, apify_output.py, price_upload.py, views.py и соответствующие шаблоны.
Проверка: 218 тестов repricer.tests прошли в изолированной копии с отдельной SQLite. Реальный платный запуск и проверка результатов выполняются владельцем.

У четырёх товаров более дешёвые карточки. У трёх CTR более низкие предложения
на уже привязанной карточке. Само расхождение текущих предложений с выгрузкой
не устанавливает, когда изменились продавцы/цены: прошлый полный ответ
внешнего Actor и его параметры здесь не восстанавливались.

Причины в коде: поиск был ограничен числом карточек, точная строка бренда
пропускала PMC PARTS MALL, а финансовый допуск не требовал отдельной проверки
минимума и охвата поиска. Новый импорт также проверяет валюту и соответствие
ID карточки её URL. Новая более низкая цена/новая карточка сбрасывает допуск.

Для Фаэтона теперь нужен отдельный свежий (7 дней) допуск точного последнего
аудита: verified identity, confirmed minimum, Kazakhstan scope, complete search
and seller review. Ни JSON, ни скриншот его автоматически не выставляют.
Неподтверждённые позиции доступны через price_review=1, с предварительной
прибылью, без добавления в закупку. Прямой и массовый POST также проверяются.
CSV использует тот же допуск. Остальные поставщики сохраняют прежний режим.

Миграция 0154 добавляет отдельные наблюдения для десятки с пересчётом по
комиссии/расходам прежнего аудита. Исторические аудиты, прайсы, постоянный
реестр, корзина, заказы и остатки не переписываются. Данные идемпотентны.

В очереди доступен JSON для всего текущего отфильтрованного списка, включая
позиции за пределами первой страницы. Поиск: бренд + полный артикул, отдельно
полный артикул, явный синоним PARTS-MALL; 5 карточек на запрос, все города из
общей настройки (сейчас 10). Платный запуск остаётся ручным. Даже этот охват
ограничен: результаты нельзя автоматически выдавать за весь Казахстан.

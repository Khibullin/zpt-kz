# Тестовые получатели всех новых заявок

Разрешено владельцем 19.10.2026, 10:24–10:25. Миграция 0122 включает все существующие карточки с is_test_seller, не меняя обычные карточки, пароли, пользователей, географию профиля или глобальные настройки рассылки. Заполняются все признаки специализации, активность и приём заявок; пауза снимается. Для тестовых контактов создаются недостающие тестовые профили в другой системе (core.Seller / service_requests.ServiceSeller). Существующие аккаунты не объединяются; новые профили не получают доступа к чужому кабинету.

Перед работой было 5 тестовых продавцов и 2 тестовых исполнителя, всего 5 уникальных WhatsApp. Ожидаемый результат: 5 тестовых продавцов и 5 исполнителей (3 новых профиля для существующих номеров). Обычная карточка AG Parts с совпадающим номером остаётся без изменений.

Nullable test_all_requests_since — явный признак подключения, действующий только вместе с is_test_seller и только для заявок, созданных после этого времени. Для таких получателей подбор, очередь и отправка обходят ограничения направления, транспорта, марки/модели, категории/услуг, города/района. Режим OFF, аварийный стоп, пауза и отключение получения остаются действующими. Снятие is_test_seller отключает исключение. Будущие карточки не включаются автоматически.

Исторические заявки и очереди не создаются и не возобновляются. Ожидающие исторические отправки подключённым тестовым получателям не отправляются. Миграция вообще не обращается к таблицам заявок/очередей. Обратная миграция данных — noop, настройки не стираются автоматически при откате схемы.

Дедупликация: при добавлении универсальных тестовых получателей не добавляется второй получатель с тем же нормализованным WhatsApp. Существующий обычный получатель, уже подходящий заявке, сохраняется.

Проверки: изолированные тесты новых/б/у запчастей, обоих видов услуг, транспорта, городов/районов, сохранения режимов и стопов, исключения обычных карточек, исторических заявок и миграции. Отправщик в тестах заменён заглушкой. Реальные сообщения не отправлялись.

# Явное формирование файлов Apify — 26.11.2026

В блоке №2 постоянно отображаются выбор сохранённого запроса текущего поставщика и кнопка «Сформировать JSON для Apify». После сброса не подставляется старый запрос автоматически. Менеджер может явно выбрать источник из истории, не открывая её отдельный блок. После выбора и формирования отображаются партии выбранного снимка; при смене запроса старые кнопки скрываются до формирования.

Если в первом блоке есть новый отбор, который уже рассчитан и подтверждён предпросмотром, кнопка отправляет штатное сохранение запроса и открывает блок №2. Сохраняются выбранные города, число карточек и размер партии. Проверка серверного подтверждения preview перед save остаётся обязательной. Если новый отбор ещё не рассчитан, пользователь получает точное указание нужного шага в первом блоке. Если нет ни выбранного запроса, ни нового отбора — показывается инструкция, без подстановки другого товара или сохранения лишних запросов.

Минимум закупки 2000 ₸ для экспорта сохраняется. Для старого снимка с меньшим порогом сообщение показывается прямо рядом с кнопкой, без перехода на страницу JSON-ошибки. История не переписывается. Текущий снимок разрешено открывать только внутри выбранного поставщика.

Проверки: 24 профильных теста, включая наличие кнопки без активного запроса, сохранение настроек при сохранении подтверждённого отбора, запрет смешивания поставщиков, все размеры партий и сохранность данных при сбросе. Синтаксис JavaScript проверен. Исходная версия для отката: 6e02bc23210331c419e3fc76862fa6bb58cb026b. Миграций и удаления данных нет.

JSON содержит параметры Actor и задания поиска, но не отправляется в Apify автоматически. Для карточек, найденных поиском, требуется подтверждение совпадения бренда и артикула.

Утверждённые правила

  1. Ассортимент: все товары последнего ACTIVE.xlsx, включая несопоставленные.
  2. Города: только отмеченные галочками из шести городов.
  3. Карточки: одна подтверждённая карточка по проверенной ссылке или 1–3 поисковых кандидата, если точной ссылки нет.
  4. Поиск: подтверждённая ссылка Kaspi, иначе название и бренд / артикул; похожие товары не считаем подтверждёнными.
  5. Продавцы: все доступные предложения, кроме AG Parts.
  6. Минимальная цена: одна самая низкая подтверждённая цена конкурента среди выбранных городов.
  7. Результат: минимальная цена, продавец, город, ссылка Kaspi, дата проверки.

Исключение AG Parts (merchant ID 30363568), проверка соответствий и расчёт минимума выполняются при обработке результатов, а не при формировании входного JSON.
